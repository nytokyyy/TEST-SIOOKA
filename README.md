# TEST-SIOOKA
Application web permettant de :
- Consulter une liste d’articles
- Ajouter des articles dans un panier
- Consulter le panier
- Retirer des articles du panier

Stack Technique
- Laravel (Backend API) -> 12.0
- VueJS (Frontend) -> 3.5.27
- Git (Versioning) -> 2.43.0

INSTALLATION
* BACKEND : make install
* FRONTEND : npm install
